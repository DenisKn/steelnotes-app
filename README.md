# steelnotes-app

Сайт приложения **Steel Notes**: https://deniskn.github.io/steelnotes-app/

- `index.html` — страница со ссылками на Google Play и RuStore (её адрес вшит в приложение для «Поделиться»).
- `privacy.html` — политика конфиденциальности (ссылка для Google Play и RuStore).

Статика без сборки, публикуется через GitHub Pages из ветки `master`. Язык (RU/EN) выбирается в `lang.js`: `?lang=` -> сохранённый выбор -> язык браузера.
